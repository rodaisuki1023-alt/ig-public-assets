# 保育園の持ち物チェックリスト
朝の支度で「あれを入れたかな」と迷うときは、毎日必要なものと、曜日や行事に応じて必要なものを分けると確認しやすくなります。下記は一般的な例です。必要品・数・持ち込みルールは通っている園の案内を優先してください。

| 毎日確認するものの例 | 必要に応じて確認するものの例 |
|---|---|
| 連絡帳・連絡手段、着替え | 昼寝用品、指定の袋 |
| おむつ、おしりふき | 季節の着替え、雨具 |
| タオル、水筒（園で指定がある場合） | 行事用品、週明けの持ち帰り品 |

## 前夜に準備、朝に最終確認
1. 園の予定を確認して、明日の持ち物をまとめる。
2. おむつなどはバッグに入れる数と家の残りを別々に確認する。
3. 足りない品だけを買い物メモに入れる。購入前に家にある分をもう一度確認する。

## チェックと在庫は別の記録に
バッグに入れたというチェックと、家の在庫が何袋あるかは別の情報です。持ち物をチェックしただけで在庫数が自動的に減ると、かえって補充の判断を誤ることがあります。両者を分け、購入や消費を記録するときだけ数量を変更する運用がおすすめです。

# おむつの買い忘れ・買いすぎを防ぐには
おむつはサイズやテープ・パンツの種類によって使い分けるため、同じメーカーでも別の商品として記録すると管理しやすくなります。

## 3つの情報を分ける
- 商品名：メーカー、種類、サイズ、1袋の枚数。
- 在庫：未開封の袋数と、必要に応じて開封中の残り。
- 補充：買い物へ追加したか、すでに購入したか。

## 補充の目安は家庭ごとに設定
例えば未開封の予備が1袋になったら購入を検討する、というルールから始められます。必要数は消費ペース、買いに行ける頻度、サイズ変更の見込みで変わります。特定の数量をすべての家庭に推奨するものではありません。

## 家族が買ったら記録を更新
買い物メモの「買った」を確定した後、実際の数量・種類を確認してストックへ反映します。買っていない品を先に在庫へ足さないことがポイントです。

関連記事：保育園の持ち物、家族の買い物分担。

Description: 夫婦や家族が別々に買い物へ行くとき、欲しい物・購入済み・在庫を混同しない管理方法を解説します。

# 家族で買い物を分担するときの確認ポイント
「買っておいて」と伝えただけでは、相手が買ったのか、家に残っているのかが分からないことがあります。購入前と購入後で確認する情報を分けましょう。

1. 買う前に在庫・サイズ・容量を確認する。
2. 買い物メモに必要な数量を入れる。
3. 購入した人が購入を確定し、在庫に反映された内容を確認する。
4. 通信できないときは反映を確認するまで、同じ購入を繰り返し登録しない。

家族共有機能を紹介する際は、対応端末、招待・退会、通信が切れた場合、機種変更時の復元を実測と一致させる。旧写真URLの問題が解決するまでは家族共有の安全性を保証する宣伝をしない。
