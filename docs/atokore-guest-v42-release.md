# あとこれ v42：Googleなし招待・機種変更案内

## 公開内容
試用版 /preview-baby-v19/ の参照だけをv42へ更新する。ソースはDraft PR #62の固定SHA `2e9632fbc841d2de4f9b0e6e0992231aa507396f`。ソースブランチはmainへマージしない。通常版アプリと過去の試用版の参照は維持する。

招待リンクを開くとコードが入り、表示名を入れて「Googleなしで共有に参加する」を押せる。コードだけ受け取った場合はマイページ → 家族共有 → 「招待コードを入力して参加する」。リンクを開くだけでは匿名アカウントも共有データの変更も発生しない。参加後は保存した匿名セッションで、アプリを開いたとき・オンライン復帰時に同期する。

## 機種変更
Googleで参加済みなら、新端末で同じ試用版URLを開き、マイページ → 家族共有 → 同じGoogleアカウントでログインする。既存の世帯を取得し、新しい世帯は作らない。新端末に在庫があれば内容を確認して共有データを使うか選ぶ。

復旧できるのは共有先へ送信済みの在庫・買い物リスト・いつものリスト。写真・未送信の変更・端末内の控え・表示設定は対象外。Googleは本人確認であり、Google Driveへのバックアップ機能ではない。共有を始めていないローカル在庫はログインだけでは復旧しない。

Googleなしで参加し、端末の保存情報を失った場合は、作成者が旧メンバーを「外して再招待」し、新端末で新しい招待を受ける。共有済みの記録は維持する。ゲストからGoogleへの後付け連携は未実装。
