## 変更

大きな宣伝バナーと常設3指標、重複する買い物ボタンを整理。追加ボタン2つ、該当時だけの「気になるストック」、最近3件の変更履歴を表示。買い物件数は下のタブへまとめ、5つのメニューを1列に維持する。

共有中は既存のメンバー確認付き `hh_changes` の適用済み履歴を表示。同じ時刻・表示名・操作・対象が一致する一括操作をまとめる。未共有ではこの端末の操作履歴を表示し、家族履歴と重複させない。履歴取得失敗やオフラインでの起動には再試行を案内する。読取要求の8秒打切り・ログアウト時の破棄・遅れた応答の無視を実装。最終同期は共有エンジンの成功時刻を表示する。

期限を過ぎた商品、期限が近い商品、数量が目安以下の商品を表示する。最初は2商品、それ以降は「ほか○商品を確認」から確認できる。商品を開くだけでは数を変更しない。写真は従来どおり端末内に保存し、共有しない。
