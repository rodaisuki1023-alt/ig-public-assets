# あとこれ レシート v49：iPhone実機での試用チェック（短縮版）

目的：サーバーやテストでは測れない、実機での使いやすさを確かめます。
測るもの：
- 読み取りにかかる時間
- 直した行の数
- 確認・修正にかかる時間
- 取り込み後の在庫の数量
- 再起動・オフラインのときの動き

**守ること：**
- レシートの写真・会員番号・決済情報は、どこにも送らない・貼らないでください。記録は下の表の数字だけです。
- 試用版（試用URL）だけで行います。本番のデータでは行いません。
- 家族共有の確認は、サーバー変更を承認・適用するまで対象外です。

## 準備（1回だけ）
1. 試用版を Safari で開き、ホーム画面に追加して、そこから開きます。
2. Wi-Fi につないだ状態で、マイページ →「レシート一括補充」を開きます。
3. 最初の読み取りで「読み取りの準備（初回のみ）」が出たら「ダウンロードして読み取る」を押します。その時間も記録します。

## 1枚ごとに記録すること（まずは3〜5枚）
撮影は、レシート全体が入るように、真上から撮ります。横向きのままでも構いません。

| 項目 | 測り方 |
|---|---|
| 読み取り時間（秒） | 「商品名を解析」を押してから、「読み取り結果の確認」が出るまで（ストップウォッチ） |
| 商品の行数 | レシートに印字された商品の行数 |
| 直した行の数 | 名前を直した行、数量を直した行、選択を変えた行、追加・削除した行を、それぞれ1回と数える |
| 確認・修正の時間（秒） | 確認画面が出てから「選んだ○件を確認画面へ」を押すまで |
| 読み落としの有無 | 「写真全体を見る」で写真と見比べ、一覧にない商品があったか（あり／なし、あれば何行） |
| 取り込み後の数量 | 取り込んだ商品のうち2〜3品で、在庫の数量がレシートの購入数どおり増えたか（はい／いいえ） |
| 気づいたこと | 文字の小ささ、行の画像の見やすさ、迷った操作など（商品名は書かない） |

## 再起動・オフライン（1回ずつ）
1. **再起動：** アプリを完全に閉じてから、もう一度開きます。レシートを1枚読み、「読み取りの準備」が**出ないか**確認します。
   - 出た場合も失敗ではありません。端末側で保存できなかった可能性があります。そのときは、確認画面に保存できなかった旨の表示が出ていたかを記録します。
2. **オフライン：** 機内モードにして、レシートを1枚読みます。読み取れるかを記録します。
   - オフラインでも読み取りは端末の中で行います。部品が保存されていない場合だけ、「読み取れませんでした」になります。
3. 機内モードを解除します。

## 結果の扱い
- 記録した数字は、**この端末・この数枚での結果**です。一般的な精度や速度として扱いません。
- 読み取りに失敗した場合や、数量が合わなかった場合は、何が起きたか（画面の文言）だけを記録します。レシートの写真は共有しないでください。
