## 公開後のiPhoneでの確認手順（オーナー）

ホーム画面に追加済みの「あとこれ」と、Safariの両方で確認する。家族共有の操作は見るだけで、変更しない。

1. **更新**：アプリを開き、一度閉じてもう一度開く。マイページの更新履歴などで v48 系の表示のまま、ストックや買い物リストの中身が更新前と同じであることを確認する。
2. **月齢検索（ストック）**：ストックの検索に「7ヶ月」「7か月」と入れる。7か月の商品だけが出て、17か月・27か月の商品が出ないこと。
3. **月齢検索（商品追加）**：追加 → 離乳食 → 和光堂 → 検索に「7ヶ月」。7か月頃からの商品が出ること。ピジョンで「7か月」と入れて、7ヵ月頃~の商品が出ること。
4. **重複の注意**：買い物リストに同じ商品を2回追加する（例：「牛乳」を2回）。リストの上に「同じ名前・単位の商品が複数あります」と出て、数量や行は変わらないこと。確認後、片方を削除する（自分のテスト用の行だけ）。
5. **保存・購入・取り消し**：買い物リストの商品で「買った」→ 画面下の「元に戻す」。ストックの数量と買い物リストが元に戻ること。
6. **オフライン**：機内モードにしてアプリを開き直し、ストックと買い物リストが表示されること。戻したら機内モードを解除する。
7. **共有の変更履歴**（家族共有中の場合）：マイページ → 家族と共有 → 変更履歴。「null」と表示される行がないこと（実行者を特定できない行は「実行者不明」）。
8. **押しやすさ**：320px相当の小さい画面（iPhone SE など）があれば、ボタンが押しやすく、横にずれないこと。
