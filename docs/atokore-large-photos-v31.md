# 試用版 v31: 商品画像を大きく表示

「アイコンが小さく写真も見分けづらい」という実機フィードバックへの調整。
ストックの44px固定画像をカードの内幅いっぱい・高さ96pxの枠へ拡大。
ホーム画像は32px前後から48pxへ、詳細写真は96pxから224pxへ、設定時のプレビューも224pxへ拡大。
写真全体を表示し、縦横比や内容を変える切り抜きは行わない。

3列・メーカー背景・画像上の44pxの＋／−操作範囲を維持。
画像が大きくなる分だけカードの高さは増えるが、商品名・補足の2行表示と下部操作行なしを継続。
画像の元データ、写真の圧縮・保存処理、IndexedDB、在庫保存キーは変更しない。
通常版や家族共有Draft #17には反映しない。

4幅の既存ブラウザ回帰で、画像の拡大、操作との重なり防止、横はみ出し、カード高280px以下、
写真の保存・再表示・キャンセル・元に戻す・保存失敗時の保護を確認する。
実機での見分けやすさは公開後の確認項目。

ソースPRはDraftを維持しmainへマージしない。公開PRで試用版固定参照と検証値のみ更新する。
