## ユーザー承認に基づく変更

- 画像見本の白・ミント色のおむつを元に、くまのワンポイント入りのオリジナルアイコンを作成。おしりふきも水色の包装と白いフタ、くまのモチーフで統一。
- 画像は256pxの透明背景WebP。おむつ11,350bytes、おしりふき11,810bytes。実際のメーカーのロゴ・商品包装ではない。
- 商品選択、追加予定トレイ、ホーム、ストック、買い物、いつものリストで共通のカテゴリ画像を使用。ミルクや食品・日用品の従来機能は維持。
- 「いつものリスト」は、リスト名→商品を選ぶ→商品一覧と数量→下部の「ストックに追加」「買い物へ追加」の横2列に整理。
- 商品名の手入力とリスト削除の管理は折りたたみへ移動し、どちらの機能も維持。
- 追加先の2ボタンはスクロール領域の外へ置き、320px幅でも横並びで触れるようにした。
- 買い物への追加も商品・数量・追加先を確認後だけ保存。キャンセル・保存失敗時は変更せず、短時間の重複操作を防止。

通常版のアプリファイルには変更を入れず、Pages workflow の試用版ソースSHAだけを変更する。試用版の保存キーはv19のまま。初期化・一括変換は行わない。家族同期は無効のまま、PR #17は変更・マージしない。

## 画像の制作記録

画像はbuilt-in image generation toolで作成し、アプリ表示用にWebPへ最適化。元の生成PNGを保持し、アプリには小さい最適化ファイルだけを同梱。

- `atokore-live-v125/icons/baby/diaper-bear-v24.webp`
- `atokore-live-v125/icons/baby/wipes-bear-v24.webp`
- プロンプト・用途：同ディレクトリの `README.md`（ソースPR #28）

両画像を試用版自身のService Workerキャッシュに追加。別アプリや通常版のキャッシュには触れない。初版のキャッシュはv24。ホームの省略表示でも元の商品データから正しい画像を選ぶ修正を加え、関連JS・CSSとキャッシュをv25へ更新した。追加先ボタンの白文字とのコントラスト比は、ストック4.95:1・買い物5.29:1。
