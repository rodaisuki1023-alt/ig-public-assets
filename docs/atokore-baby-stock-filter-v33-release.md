# 試用版 v33: ベビーのストックを種類で絞り込み

ストックでベビーを選ぶと、その下に「すべて・おむつ・ミルク・おしりふき・その他」を表示する。
登録済みの商品名から表示時に分類し、在庫データ・数量・写真を書き換えない。
商品名検索と併用できる。フォローアップミルク、半角オムツ、お尻拭き表記にも対応する。
分類に当てはまらないベビー用品は「その他」に残す。
一括操作の全選択は表示中の商品のみが対象。種類を変更すると選択を解除し、隠れた商品の誤操作を防ぐ。
他のカテゴリーへ移動して戻ると、ベビー内の絞り込みは「すべて」に戻る。
追加画面のおむつ・ミルク・おしりふき選択、写真と重なる＋／−、3列のカードは維持する。
