# 初期在庫を空にする変更に伴うテスト修正（2026-11-12 JST）

## 今回の結論

PR #99 head `529914e3decd919340684919a0929b8b2886698c` の Trial Checks は失敗している。CIログを取得し、商品写真・保存ロックの2種類のテストが、存在しなくなった初期サンプル行をクリックしようとしてタイムアウトしていることを確認した（Chromium/WebKitで計4件）。アプリの初期値を戻さず、テストの合成データ準備を明示する候補を作成した。

優先度は **P2：PR #99のレビュー・公開判断を妨げる回帰検証の不足**。既存の保存保護を弱めないことを優先し、テストの削除・スキップ・待ち時間延長・検査対象の削減は行わない。

## 変更したこと

1. `product-photos-v30.spec.cjs`：通常版の**試験用コピー**に保存済み合成データを用意してから商品詳細を開く。写真UIが通常版で無効のままという検査を維持し、その操作で保存データが変わらないことも検査する。実際の通常版サイトや実世帯へデータを投入するものではない。
2. `storage.spec.cjs`：保存ロックで空の一覧になることを確認した後、画面操作を試すためだけの合成行をメモリへ用意する。壊れた保存文字列は一切置き換えない。＋操作後に空の初期状態へ戻ることも検査し、追加・編集・元データのファイル出力という従来の保存保護検査を維持する。

アプリ本体・SQL・公開元は変更しない。PR #99の上に積む別Draftとし、#99の既存ブランチや他PRは書き換えない。
