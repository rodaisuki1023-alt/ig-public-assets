# あとこれ v43：承認済みホーム画面案

2026-10-23、ユーザーが調査に基づく画像案を承認し、試用版への実装を依頼。

## 画面

- 上部は「あとこれ」「わが家のストック」、共有状態と最終同期日時。
- ストック追加・レシートで追加の2操作。大きな宣伝バナー・常設3指標・重複した買い物ボタンを整理。
- 気になるストックは該当時だけ表示。期限超過・期限間近を優先し、数量不足と重複しても1商品1行。最初は2商品、それ以降は専用の確認画面で表示。
- 家族共有中はサーバーが適用を確認した履歴のみ表示。同じサーバー時刻・表示名・操作・対象が一致する一括操作をまとめ、ホームには最新3件、詳細には取得済み最大50操作を表示。
- 未共有の人は端末内の操作履歴を表示。共有履歴と混ぜない。アプリ更新内容はマイページから確認できる。
- 一括追加は保存成功後に端末履歴を1件記録。保存失敗時に成功履歴は作らない。
- 買い物件数は下のタブに集約。5つのメニューを1列に維持。

## データの扱い

既存の認証・世帯メンバー確認付き `hh_changes` を利用。スキーマ・権限・写真共有は変更しない。共有履歴はメモリー内で世帯とログイン利用者に紐付け、ログアウト・退出で破棄する。取得失敗時は古い履歴であることを明記し、再読み込みを案内。読取要求は8秒で打ち切り、遅れた応答で別世帯・ログアウト後の表示を更新しない。

商品名・表示名・履歴はHTMLエスケープして表示。商品行を開く操作だけでは数量を変更しない。日時は端末の暦日で計算し、存在しない日付を注意対象にしない。最終同期は既存エンジンが保存した成功時刻を使う。
