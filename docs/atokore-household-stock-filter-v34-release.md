# 試用版 v34: 食品・日用品の分類と離乳食のストック

ストックの食品・日用品も、追加画面と共通のルールで種類別に絞り込める。
食品: 肉・卵・野菜・果物・乳製品・魚・パン・主食・豆腐納豆・冷凍食品・飲み物・調味料・離乳食・その他。
日用品: 紙製品・洗濯用品・キッチン用品・掃除用品・お風呂ケア・その他。
項目が多い2カテゴリーは横1列でスクロールし、商品カードまでの縦の長さを抑える。
検索と併用でき、種類切替時の選択解除・表示中商品のみの全選択を維持する。

食品→離乳食に「おかゆ・野菜ペースト・レトルトパウチ・カップ」の一般的な候補を追加。
以前ベビーカテゴリーで登録した離乳食は、カテゴリーを移動せずベビー内の離乳食で探せる。
商品名から分類するだけで、保存済みカテゴリー・商品名・数量・写真は書き換えない。
商品名や月齢の異なる離乳食も従来の同一商品判定を維持し、種類を理由に合算しない。
レシピ・月齢判定・栄養・アレルギー管理は追加しない。需要は実利用で確認する。

メーカー公式で粉末・カップ・パウチ等の離乳食の形態を確認。特定ブランドの商品マスターは増やしていない。
