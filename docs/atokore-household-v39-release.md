# 試用版 v39：家族共有の基盤（非表示）・レシート登録の改善・はじめの案内・補充の目安

## 公開するもの
- **はじめの案内**：データを一度も保存していない端末で、普段使う物を5つまでタップで選んで始められます。
  - 確認画面から1回だけ保存します。
  - 商品ごとに「残りN以下で知らせる」を設定できます（任意）。
  - アカウント登録も、入力必須の項目もありません。
- **補充の目安**：商品の編集画面で、「要補充」に出す残り数を決められます。空欄なら、これまでどおり残り1以下で表示します。
- **レシート登録**：
  - 入り数と購入数を区別します。
  - 登録済み商品を候補に出します。サイズ・形状・容量が違う商品は候補に出しません。
  - 読めなかった行を一覧に出し、追加できます。
  - 購入日を読み取ります。
  - 同じレシートを再度読み取ると警告します。
  - 保存は確認画面からの1回だけです。
- **家族共有の基盤**：コードは入っていますが、**バックエンドが未設定のため表示も通信もしません**。
