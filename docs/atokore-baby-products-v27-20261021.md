# あとこれ：ベビー商品の選択肢整理（v27）

調査日：2026-10-21（日本時間）。メーカー公式の商品一覧を優先し、下記のプリセットだけを登録する。栄養・授乳・切替時期の助言は追加しない。

## 変更

- おむつ・ミルク・おしりふきの一覧末尾に「その他」を追加。選択時にブランド・商品名・種類・サイズを必要に応じて入力できる。数量操作でも入力を維持し、追加前に編集できる。未入力では追加しない。
- ミルクはメーカー名より商品名を大きく表示。商品ボタンを押すだけでメーカーと商品名を同時に選び、追加のシリーズ選択を不要にする。
- フォローアップ系5商品は折りたたみにまとめ、商品ごとの形状を限定する。別商品や別形状は異なる名前を保存するため、ほほえみとステップ、はぐくみとチルミル等を合算しない。
- おしりふきに「カークランド」「Rico」「baby care」を追加し、ピジョンを選択肢から外す。「包装」操作は削除し、ブランドだけで追加できる。単位はパックを維持し、本体・詰替という接尾辞は新規追加しない。
- 保存済みのピジョンや包装付きの名称は変更・削除しない。保存キーの変更・データ移行・初期化は行わない。旧名と新名の自動統合は行わない。
- 通常版UIは変更せず、試用版v19の保存キー・家族同期無効・Service Worker分離・XSS対策を維持する。既存のくまアイコンも維持する。
