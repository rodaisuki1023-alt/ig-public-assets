# 試用版 v35: 離乳食の独立カテゴリーとメーカー別商品選択

追加・ストックに独立した「離乳食」カテゴリーを用意した。
追加ではメーカー→シリーズ・表示月齢/検索→具体的な商品→数量→追加予定→確定の順に登録できる。
商品選択後は候補一覧を畳み、数量操作と追加ボタンを近づける。候補は24件ずつ表示する。
ストックではメーカー別に絞り込み、必要なら「月齢・シリーズで絞り込む」を開ける。
食品・日用品の既存の種類別フィルターは維持する。

2026-10-21にメーカー公式で確認した203商品を通常候補に収録した。
和光堂153（はじめての離乳食、手作り応援、お米を味わう離乳食、栄養マルシェ、グーグーキッチン等）・ピジョン42（レシピ、やわらかパックごはん、カップ）・森永乳業8（はじめて、オーガニック）。
キユーピーは2026年8月末で育児食の生産終了。離乳食69商品は「生産終了品を登録する」の別枠にした。
1歳半向けの幼児食は候補外。「1歳半」を12か月と誤認しない境界テストを追加した。
メーカー・シリーズ・月齢・内容量・形状を区別し、異なる商品を合算しない。数量1個は表示された販売単位1商品で、2個入りを自動で2個に増やさない。
未収録メーカーや手作りは手入力できる。ビーンスタークの旧シリーズは現行公式一覧で確認できず、自動候補には加えない。
全市場の網羅・店頭在庫の保証はしない。原典URL付きの商品データと調査範囲はソースPR内の `docs/atokore-babyfood-master-v35-research.md` に記録した。

旧「食品」「ベビー」「その他」等で登録した離乳食は表示だけを統合し、保存済みカテゴリー・名前・ID・数量・写真は書き換えない。用品（離乳食用スプーン等）は移さない。
3列・96px画像・画像上の＋/−とメーカー背景色、写真の個別保存を維持する。
通常版UI、v19の保存キー・写真DB、家族Draft PR #17は変更しない。試用版の家族同期は引き続き無効。
