# あとこれ：メーカー色とストックの商品カード（v28）

2026-10-21。利用者提供の12秒の動画を確認。画像中心の商品カードと数量操作を参考に、試用版のストックを2列に配置する。320pxでも商品名・サイズと44pxの数量ボタンを収めるため、動画の3列から2列へ調整した。

## 原因と変更

ストックのメーカー背景は `baby-focus-v17.css` の共通色 `#FFF9F5!important` が、既存のメーカー色を上書きしていた。ホームが使うブランド情報から背景色・文字色を取得する共通関数を設け、ストックへ同じ色を適用する。ビーンスターク・アイクレオ・Rico等の追加ブランドにも固定色を持たせる。メーカー不明の商品にメーカー名を推定・付与しない。

- ストックの商品は2列カード。画像を64pxで表示し、メーカー色の面、メーカー名、商品名、種類・サイズ、残り数量を表示する。
- カードを押すと従来の詳細を開く。数量変更は既存の＋／−ボタンを使う。表示変更のために保存データへ書き込まない。
- まとめて選択、検索、カテゴリ絞り込み、食品・日用品、登録後編集は既存のデータ処理とイベントを使用する。
- キーボードのEnter／Spaceでもカード操作ができ、内部の数量ボタンとは区別する。
- 買い物画面のリスト配置・アイコンサイズは維持する。
- くまのオリジナル画像とピーチ配色を維持。通常版UIには変更を入れず、別の配信PRで試用版ソースだけを更新する。

## データと公開の範囲

試用版のv19保存キー・家族同期無効・旧版とのService Worker／キャッシュ分離・XSS対策・保存失敗時の保護を維持する。データ移行・初期化・名称や数量の一括変更を行わない。ソースPRと家族共有PR #17はDraftのまま、mainへ直接マージしない。

## 検証

- Node回帰75件合格。
- 320/375/390/430pxの実ブラウザでメーカー色のホームとの一致、2列配置、はみ出し、画像読み込み、44px数量ボタン、閲覧時のデータ不変、数量変更、編集後の色の更新、再読込、検索の該当なし、まとめて選択を確認する。
- 手元ではブラウザ配布元の取得エラーがあったため、GitHub ActionsのChromium／WebKitと画面画像を使用して実ブラウザ検証する。
- iPhone実機での押しやすさ・スクロールの感触は利用者による確認が残る。
