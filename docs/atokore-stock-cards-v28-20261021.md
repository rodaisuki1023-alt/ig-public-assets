# あとこれ：メーカー色とストックの商品カード（v28）

2026-10-21（日本時間）。利用者提供の12秒動画の画像中心の商品カードを参考に、試用版のストックを2列へ変更した。320pxでも商品名・サイズと44pxの数量ボタンを収めるため、2列を採用。

## 原因と修正

ストック用CSSの `#FFF9F5!important` が既存のメーカー色を上書きしていた。ホームのブランド情報から背景色・文字色を共通取得し、ストックへ同じ色を適用する。Rico・baby care・カークランド・ビーンスターク・アイクレオ等にも固定色を設定。メーカー不明の商品へメーカー名を推測して付けない。

- ストックは画像・メーカー名・商品名・種類／サイズ・残り数量を見せる2列カード。
- カードを押すと詳細。数量変更は従来の＋／−ボタンのみ。表示・閲覧では保存データを変更しない。
- 食品・日用品、検索・カテゴリ、まとめて選択、登録後編集、キーボード操作を維持。
- 買い物のリスト配置とアイコンサイズ、既存のくま画像・ピーチ配色を維持。
