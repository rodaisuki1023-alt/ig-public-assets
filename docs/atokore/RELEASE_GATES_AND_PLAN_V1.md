- [ ] 招待＋認証＋RLSでアクセス制御。フルデータP2P送信・家族コードだけの共有は商用版では使わない。

## 開発受け渡し指示
1. 実装担当は最初に最新mainと本PRを取得し、旧コードを読む。
2. `baby-catalog.js` は独立モジュール。安全なテストとデータ移行設計を追加してから画面へ接続。
3. 変更は小さなPRへ分ける。順番：PWA/家族JS復旧 → SKU UI → OCR紐づけ → 保存互換 → 同期 → 無料モニター。
4. 既存在庫データを消さず、データ移行はまずdry-runで件数・曖昧件数を報告。
5. 事前承認なしに本番配信・広告送信・課金・リポジトリmain変更をしない。
