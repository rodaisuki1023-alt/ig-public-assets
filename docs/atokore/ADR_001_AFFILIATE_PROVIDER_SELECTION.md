# ADR-001：あとこれ 購入先アフィリエイトの初期採用先

- 決定日: 2026-10-18
- 結論: **楽天アフィリエイトを先行採用候補**とし、Amazonアソシエイトは初期実装に含めない。
- 状態: 技術・事業の設計方針として採択。外部提携承認・具体的広告掲載方法の規約適合確認をもって初めて公開可能。
- 対象: ベビー用品（おむつ、粉ミルク、おしりふき）から家庭消耗品に拡張する在庫管理Webアプリ。

## なぜ楽天を優先するか
1. 楽天は一般公開のWeb媒体で正式な商品アフィリエイトリンクの運用を比較的早く開始できる（媒体登録・禁止事項を遵守すること）。
2. Amazonアソシエイトは開始後180日以内に3件以上の適格販売による審査、公開オリジナルコンテンツ原則10件以上、モバイルアプリの別途承認などが必要。
3. Amazonアソシエイトの参加要件・プログラムポリシーには、別途合意なき価格追跡および価格アラート機能の禁止がある。将来の安値通知構想をAmazonに依存させない。
4. 楽天とAmazonのベビー・マタニティ関連基本報酬率はいずれも概ね4%（実際のジャンル分類や特別条件に従う）。基本料率だけで販路は選ばない。

## 制約と適用境界：初期実装で確定

| 対象 | 方針 |
|---|---|
| 家庭の在庫管理画面 | メーカー・シリーズ・パンツ/テープ・サイズ・包装量を自社データで識別。楽天の商品・価格APIへ依存しない。 |
| 商品写真 | 自分で撮影した写真・適法な独自素材・権利明確なアイコンを使用。楽天画像を自社の商品マスターへ流用しない。 |
| 家族ログイン・買い物リスト | 楽天・AmazonのアフィリエイトURLを埋め込まない。誤ったサイズや数量で外部購入へ誘導しない。 |
| 公開の商品紹介ページ | ログインなし・媒体登録済み・広告明示。楽天公式リンク作成で許された広告素材とリンクをそのまま使う。 |
| 商品選定 | 独自の文面とカテゴリ説明を記載。確認できない価格・割引率・ポイント数を作らない。掲載商品が在庫のブランド・サイズ・タイプ・入り数と一致するか人が確認。 |
| 商品価格 | 初期は公開ページに動的API価格を載せない。実際の販売価格は楽天のリンク先で確認してもらう。 |
| 価格追跡・値下げ通知 | 初期は**実装しない**。楽天でもAPI保存期限や限定メッセージ等の規則があり、機械的配信の適法性が未確認。 |
| 在庫切れ通知 | 自社の残数だけに基づく中立的な機能通知として検証。広告URLや外部値下げメッセージを載せない。 |
| Premium月額課金 | 楽天ウェブサービスAPIデータを有料対価に利用しない。ユーザー自前の消費履歴・独自分析・バックアップだけを候補とする。 |
| Amazon | 初期はAPI、特別リンク、商品画像、価格アラートを実装しない。Amazon側の承認取得、要件確認後に新たなADRで評価。 |

## リリース前に必ず確認すること
- [ ] 楽天アフィリエイトへの媒体登録（**公開の**商品紹介ページURL）。アプリ本体とは別掲載面を明示。
- [ ] 公開商品紹介の広告表記（PR）、紹介文、リンク先と掲載素材の規約順守。
- [ ] 現在の閲覧制限対象へのリンク配布ルールに照らし、プライベートアプリから公開媒体に遷移する設計が『実質的な限定媒体での広告』にならないか確認。懸念が残ればアプリ内導線はOFF、一般検索・公開メディアの集客のみに留める。
- [ ] 商品の同一性（ブランド/シリーズ/タイプ/サイズ/入り数）を人が検証。自動同一視しない。
- [ ] アフィリエイトリンクをメール・DM・LINEなどの限定配信に載せない。価格通知・広告プッシュは未承認としてOFF。
- [ ] 月額課金実装時に楽天APIへの依存が混入していないことを静的検査。
- [ ] 成果報酬の計算や広告リンクを設置する権利は、審査・規約変更・提携停止に左右される。機能スイッチを持つ。

## 保留事項・再評価の条件
- アプリのログイン会員から一般公開の広告ページへの導線は、構造を分けただけで規約適合が保証されない。広告開始前に適合評価が必要。
- Amazonを採用する条件：審査承認、媒体としての承認、アプリ無料アクセス要件、API要件、価格追跡機能との分離方針を全て確認できた場合。
- 楽天の価格データを使った自動検知を採用する条件：公開媒体の独立運用、API有償利用禁止への抵触なし、キャッシュ（価格原則24h）期限遵守、通知チャネルの合法性/規約適合の確認を全て満たした場合。現時点では採用しない。
