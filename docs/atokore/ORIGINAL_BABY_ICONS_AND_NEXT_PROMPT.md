# あとこれ：ベビー用品オリジナルアイコン仕様／実装プロンプト（2026-10-19）

## 狙い
メーカーの公式ロゴやパッケージ画像は使わず、オリジナルのSVGイラストと実際に登録されたブランド・種類・サイズ・入り数の**テキストラベル**で、買い間違えを防ぐ。

## 確定した表示ルール
| 品目 | 絵柄 | ブランド | ラベル |
|---|---|---|---|
| おむつ | 抽象化した布型・包装を連想する線画（パッケージ模写なし） | 登録時に入力したブランド名を通常の文字で表示 | パンツ/テープ、新生児/S/M/L/ビッグ、内容量（入力されていれば） |
| 粉ミルク | 汎用の缶を表す丸角線画 | 登録時の文字 | 缶/キューブ/スティック/液体、容量（入力時） |
| おしりふき | シート容器の抽象線画 | 登録時の文字 | 内容量 |
| その他のベビー用品 | 汎用の角丸箱を表す線画 | 実際に入力したときのみ | 存在する情報だけ |

配色：おむつ＝淡いサーモン、ミルク＝淡いラベンダー、おしりふき＝淡いミント、その他＝薄いベージュ。背景色・形状・塗りは自作。メーカー独自の図案・キャラクター・配色配置・ロゴ文字体は使用しない。

## ソース実装
- `atokore-live-v125/baby-visuals.js`：inline SVGの描画、表示時のラベル分解、在庫・買い物・カテゴリ候補への装飾、ベビー用品のメーカー・シリーズ・品目・サイズ・入り数の簡単入力。
- 在庫データの保存キー `atokoreTrialV4`、レシートOCR、P2P同期データ形式に変更なし。商品名は既存のテキストへ明示的に反映。**独立SKUのDB化は別PR**。
- `atokore-live-v125/service-worker.js` にスクリプトをプリキャッシュし、オフラインでも図案を描画。
- 本モジュールはAPIアクセス、アフィリエイトリンク、画像取得、追跡、課金を実施しない。

## 制約
- 不明なブランドやサイズを勝手に補完しない。旧商品「オムツ」の表示はおむつ絵柄のみ。
- 公式ロゴ、公式パッケージ配色・帯、キャラクター、商品画像は無断転載・模倣しない。
- デザインの独自性はリスク低減に役立つが、著作権・商標・不正競争防止法への完全な適合を保証するものではない。
- 入り数は販売商品により変わるので、自動入力しない。購入先広告・ポイント表示は別途審査後。
- iPhone Safari、幅320/375/430px、既存ボタンのタップ領域、レシート読取、在庫選択を回帰テストする。

## Claude Code / Work用の次段階プロンプト
> 最新mainと直近のPRを取得し、あとこれのベビー商品登録を正式な構造化データに拡張してください。現行 `atokoreTrialV4` のエクスポート/復旧を先に整え、既存データを維持したまま `brand/series/form/size/packageCount/packageUnit` を新規任意フィールドとして導入。`baby-visuals.js` のアイコン描画は維持し、テキスト文字列からの推測より構造化フィールドを優先。別ブランド・別サイズ・別包装は自動統合せず、OCR結果は候補として人が確認してから在庫へ追加。PRで既存テストを実行し、iPhone Safariの見た目と操作性を検証。楽天等のAPI・広告・課金には接続せず、検証済みのプレビューURLを提示してください。

## 今回の完了範囲
商品を識別しやすい表示とガイド付き商品名入力まで。独立SKU永続化、商品画像の公的ライセンス取得、販売先比較、サブスク、同期改修は対象外。
