# v30: 利用者の商品写真

商品詳細の「写真を設定」→「撮影・写真を選ぶ」→プレビュー→「この写真にする」。
ホーム・ストック・詳細に反映し、写真を変更／元のアイコンに戻せる。
食品・日用品も対象。既存の3列・左右上の44px在庫操作は維持。

## 保存と安全性

- 写真の外部送信・公開・共有は行わない。試用版専用IndexedDB `atokorePreviewProductPhotosV19` に保存。
- 在庫localStorageに画像や参照を追加しない。在庫保存キー・家族同期は変更しない。
- 20MB以下のJPEG / PNG / WebP / HEICを識別子で検証。HEICはブラウザでデコードできる場合のみ対応。
- 256px正方形キャンバスに全体が収まるよう描画し、80KB以下のJPEGへ再変換。EXIF等の元メタデータはコピーしない。
- SVG、任意URL、壊れたデータは採用しない。名前・ファイル名はHTMLへ埋め込まない。
- IndexedDBのトランザクション完了後にだけ表示を更新。失敗時は旧写真と在庫を維持。
- 商品ID・全文の商品名・単位をキーに含め、復元等でIDを再使用した別商品に写真を誤適用しない。
- 商品編集の保存成功後に写真のキーも移行する。移行失敗は通知し、在庫保存は取り消さない。
- 写真は同じブラウザ内だけ。既存JSONバックアップ・家族共有には含まれず、ブラウザのサイトデータ削除で消える。この制約は設定画面に表示。
- 通常版や他の試用版パスでは写真UIを起動しない。

## 権利確認（2026-10-21）

特許庁の商標権の効力・出所表示に関する資料、文化庁の私的使用と一般公開の区別を確認。
自分で撮った商品の写真を端末内の在庫識別に使う機能は、他社ロゴを当アプリのブランドにしたり、
メーカー公式写真を共通カタログとして再配布する行為とは利用態様が異なるため、この限定用途で実装する判断。
個々の写真の適法性を保証するものではない。撮影者の権利、パッケージに描かれた作品等の著作権も商標とは別に存在しうる。
写真設定画面は、自分で撮った写真または使用許可のある写真を案内する。

ブラウザ検証: 4幅のプレビュー中止・保存・再読込・ホームとストック、別サイズの分離、
画像の再変換・メタデータ除去、破損画像・SVG拒否、保存失敗・保存領域利用不可、
商品名編集後の引継ぎ、別商品へのID再利用、アイコンへの復帰、通常版でUIが出ないこと。
実機iPhoneの写真選択・HEIC形式は別途確認が必要。
