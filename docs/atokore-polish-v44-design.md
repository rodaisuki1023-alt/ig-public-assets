# あとこれ試用版 v44

2026-10-24。ユーザーが改善案①〜⑤、追加確認画面からの直接編集、写真なしカテゴリー別一覧を依頼。

- 数量変更：直前の実際の増減分だけを戻す。他の商品・メモ・家族の後続加算は維持。削除・単位変更・負数になる場合は取り消さない。
- 購入済み：未共有時は購入した数量と買い物行だけを戻す。共有時はオンラインで本人の適用済み操作をサーバーで原子的に補償する。同じ要求の再送は一度だけ有効。消費済みなどで戻せない場合は変更せず案内する。
- ホームの補充：数量不足の商品のみに独立ボタン。期限だけの注意には出さない。登録済みの商品は「買い物に追加済み」とし、連打で数量を増やさない。
- 写真共有：既存の端末写真を自動送信しない。明示的に共有すると、80KiB以下のJPEGを専用privateバケットへ。ストックの共有IDで対応付け、参加中の家族だけが読める。ログアウト・世帯変更でメモリーキャッシュを破棄。端末だけの写真と共有写真の復旧範囲を区別する。
- 数え方：「使用中を含む個数／未開封の予備だけ」と任意の「使用中あり」。既存数量を自動換算しない。
- 履歴：サーバーが実際の変更前後・商品名・単位を記録。旧履歴には推定の前後値を作らない。詳細は月日・時刻も表示。
- 確認画面：商品名またはアイコンから追加予定を編集。確認画面へ戻しても、最終追加ボタンまでは実在庫を書き換えない。名称・追加数量・カテゴリー・期限・場所・メモ・数え方を反映。
- ストック表示：「写真付き3列／写真なし・詳細一覧」を画面上で切り替え。後者はカテゴリー見出しと1商品1行。検索・絞り込み・複数選択・数量操作を維持。表示設定は端末ごとに保存する。

## 検証

実SQLによる取り消し・再送・本人確認・家族の後続変更・写真権限、ブラウザ2人の参加・写真共有・ログアウト、320/390/430px、保存前の編集と確定保存、既存全機能を検証する。実スマホ2台の利用確認は公開後にユーザーが行う。

ソースPRはDraft。通常版は変更せず、別の公開用PRで検証したソースSHAだけを固定する。DB変更は既存APIに互換性を保った追加であり、通常版アプリはこのDBに接続しない。
