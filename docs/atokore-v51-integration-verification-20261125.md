## 4. Chromium の断続的な失敗と、OCRテストの停止

- **Chromium「execution context destroyed」**（#109で4回中1回）
  - ナビゲーションの記録と失敗時のトレース保存を追加した 4fbb41a 以降、再発していません。
  - 同じSHA 2cc4f51 で4回実行し、Chromium は4/4成功しました。
  - 再発していないため、原因は**特定できていません**。
- **WebKit の OCR テストの停止**（receipt-photo:101、横向きの写真）
  - 2回目を観測しました。2cc4f51 の4回中1回（run 45598097900、job 139149429392）です。
  - 通常は13.8〜14.6秒で終わるテストが、結果画面を200秒待って失敗しました（3.4分）。遅いのではなく、止まっています。
  - 他のWebKitテスト309件は成功しています。コードは同じSHAなので、アプリの変更ではなく、WebKitでの読み取り処理の止まり方が一定しないものです。
  - 原因は**特定できていません**。CIの成果物には、スクリーンショットしか残っていませんでした。
  - そのため、このテストに**失敗時だけ**記録を残す診断を追加しました（待ち時間・再試行・合格条件は変えていません）。
    - 記録する内容：最後の進み具合の表示、読み取り部品の取得の開始と完了の時刻、コンソールの警告とエラー、crossOriginIsolated、CPU数。
    - CIのログに `[ocr-diag]` として出力し、テスト結果にも添付します。
  - ローカルのChromiumで、わざと失敗させたときに記録が出ることを確認しました。
  - OCRは非表示のまま（#108）なので、公開機能への影響はありません。ただし、OCRを再提供する前の必須確認項目として残します。

## 5. A1（写真の旧URL）の隔離検証

**分かっていること（試用環境での実機確認、2026-11-23）**
- 除外した後でも、以前取得した Storage の URL に対して CDN が HIT/200 を返しました。
- no-store・短いTTL・nonce では防げませんでした。

**今回、コードと隔離環境で確認したこと**（`tests/atokore-photo-legacy-closure-v51.test.cjs`、PGliteで実マイグレーションを使用）
1. **写真ゲート**
   - 出荷するJS・HTMLのどこにも `/storage/v1/object` と旧バケット名がありません。
   - 写真は POST のゲート（`functions/v1/atokore-photo-gateway`）だけを通ります。
   - `photoGatewayEnabled` の既定値は `false` です。
2. **旧URLの廃止（段階1の草案、`atokore-photo-legacy-close-writes-v51.sql`）**
   - どのクライアントも旧バケットへ新しく追加できなくなります。
   - 既存の写真は、移行するまで家族に表示されたままです。
   - 除外されたメンバーと部外者は、オリジンで拒否されます。
3. **移行**
   - service_role 専用の一覧で、参照中の写真と孤児を分けます。
   - 段階2（`atokore-photo-legacy-close-reads-v51.sql`）は、旧バケットに1件でも残っているとき、または段階1が未適用のときは実行を拒否し、何も変更しません。
   - 「コピー → CAS で切り替え → Storage APIで削除」の後にだけ、クライアントの読み取り・削除の経路をすべて閉じます。
   - コピー部分は既存の `photo-legacy-migration-rehearsal-v50` で検証済みです。
4. **認可の失効**
   - 新しいパスへのゲート判定は、除外したメンバーと部外者を次の要求から拒否します。旧パスは切り替え後には認可されません。

**まだ合格していないこと（P1 FAILのまま）**
- CDN に残った旧URLの応答は、ローカルでは試験できません。無料プランには purge がありません。
- 実プロジェクトで「旧オブジェクトを削除した後、以前のURLが画像を返さなくなる」ことを、時間を置いて測る必要があります。オーナーの承認と、合成データのA/B/Cが必要です。
- CAS による切り替えの本番用RPCと、Storage APIで削除するワーカーは、別途レビューと承認が必要です。
- 一度端末に保存された画像は回収できません（仕様として明記）。
